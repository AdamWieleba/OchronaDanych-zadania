Adres | kod http | czy widać listę plików:

/wewnetrzne/  403  nie
/materialy/notatka.txt  200  wyświetla zawartość pliku
/wewnetrzne/plan.txt    403  blokuje dostęp do zawartości pliku

Jeden z wpisów odmowy dostępu:
web-1  | ... [authz_core:error] ... AH01630: client denied by server configuration: /usr/local/apache2/htdocs/wewnetrzne/plan.txt


Wyłączenie listowania jedynie ukrywa zawartość katalogu, ale nie blokuje dostępu do plików których adres znamy, podczas gdy blokada dostępu całkowicie uniemożliwia dostęp przez http.

Różnice przed zmianami:
/materialy/  403  nie
/wewnetrzne/  403  nie

Wyjaśnienie: w nginx domyślnie listowanie jest wyłączone, odwrotnie niż w apache

Po zmianach wszystko jest tak samo jak dla apache (location /wewnetrzne/ { deny all; })
